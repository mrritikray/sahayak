Safe configuration

Put Twilio credentials in a local .env file. Never paste credentials into forms, commit them to Git, or include them in screenshots. Outbound messages do not require a public URL; inbound replies and delivery callbacks do.

Only authenticated Twilio signatures are accepted at /webhooks/twilio. Demo mode never bypasses signature verification.

Before going live, create a private family account, turn off Demo Mode, and use a new database. Do not expose the seeded demo account to the internet.

See the README for tunnel setup, Twilio Sandbox restrictions, backups and privacy limits.
